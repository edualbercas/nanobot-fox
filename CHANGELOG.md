# Changelog

## 1.1.0

- Expanded tab and window management.
- Added page interaction helpers for select controls, key events and hover.
- Added downloads, sessions, top sites, browsing-data and permission actions.
- Added a generic `browser_api` dispatcher for additional Firefox WebExtensions methods.
- Added capability discovery through `get_capabilities`.
- Improved Native Messaging reconnection and increased the command timeout to 120 seconds.
- Improved HTTP request validation and bearer-token comparison.
- Rewrote the Nanobot skill and installation documentation with API examples and security limits.
